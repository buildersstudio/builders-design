# Builders Design

The design platform of Builders Studio: competitors, brand variants, brand book, presentations, landing pages and social assets for every venture in the studio.

Content is files in `public/ventures/<slug>/`, created by founders through their own models (Claude Code or any coding agent) and pushed to this repo. The rules those models follow are in [AGENTS.md](AGENTS.md) and [BRANDING.md](BRANDING.md).

```bash
npm install
npm run dev     # http://localhost:4330
npm run shots   # capture competitor headers
```
