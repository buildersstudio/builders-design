02 · How Krans reads

Every claim has to earn its place on the model.

Each input is broken into its smallest defensible unit, a passage in someone’s own words, and placed against the part of the model it touches. Four rules decide how much it carries.

Cited

Pinned to a person and a moment.

A learning is a passage in someone’s own words, linked to the call, thread or document it came from.

Graded

Graded from E0 to E5.

From a vague remark to someone putting something at stake. The grade sets how much the learning can carry.

Hardened

Heard again, it hardens.

One buyer saying it is noise. The same thing heard across several conversations hardens into a signal.

Aged

Unrepeated, it fades.

A claim nobody repeats for sixty days loses weight, and so do the positions built on it.

The evidence scale

Not every sentence weighs the same.

Krans grades every learning before it touches the model, so a passing remark never outweighs a signed budget.

03 · Evidence ages

Evidence ages. So does confidence.

A signal nobody has heard again for sixty days loses weight, and the positions built on it soften with it. Fresh evidence restores it. What you see is always the state of the evidence today.

  • Decay is automatic, and visible.
  • Promotion never runs backwards. Weight does.
  • Fresh evidence restores it in a day.
