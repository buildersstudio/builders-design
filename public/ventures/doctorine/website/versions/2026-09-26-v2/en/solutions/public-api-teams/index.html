FAQ

Questions

Do we need to move our docs portal?

No. The eval and the gate work on the docs you host today. The Doctorine portal is an option, not the entry point.

Can it tell us whether a change is breaking?

The gate classifies what changed in the spec and which surfaces it touches. When it cannot decide whether a behaviour change is a fix or a breaking change, it asks a person and records the decision in the receipt.
