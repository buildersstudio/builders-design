Gegenereerde interfaces: docs, SDK's, CLI, MCP en skills uit één spec

Ontbreekt er een interface, dan genereert Doctorine die uit dezelfde goedgekeurde OpenAPI-spec: een gehost documentatieportaal, TypeScript-, Python- en Go-SDK's, een CLI, een MCP-server en Agent Skills. Elk gaat door dezelfde gate, dus alleen wat slaagt wordt gepubliceerd.

Word designpartner →Hoe de gate werkt

Eén release, voor elke manier waarop ontwikkelaars en agents werken.

Hetzelfde veld, hetzelfde voorbeeld en dezelfde versie op elke interface. Verandert de spec, dan veranderen ze samen of helemaal niet.

Waarom het de upgrade is

Genereren is nu goedkoop. Bewijs niet.

Coding agents schrijven op verzoek een client uit een spec, en gratis generators dekken de gangbare talen. Wat schaars blijft, is bewijs dat de output klopt voor deze release.

Daarom begint Doctorine met de evaluatie en de gate. Gegenereerde interfaces zijn er wanneer je ze nodig hebt, en ze moeten dezelfde taken halen als de interfaces die je al hebt.

FAQ

Vragen

Welke interfaces kan Doctorine genereren?

Een gehost documentatieportaal, TypeScript-, Python- en Go-SDK's, een CLI, een MCP-server en Agent Skills, allemaal uit dezelfde goedgekeurde OpenAPI-spec.

Moeten we ze allemaal gebruiken?

Nee. Genereer alleen de interfaces die je mist en houd de rest. Beide gaan door dezelfde release gate.

Waar staat de SDK-code?

In repositories die jij kiest. Doctorine schrijft gegenereerde code en releasebranches via zijn GitHub App en opent pull requests die je branch protection respecteren.

Kunnen we configuratie van een andere leverancier meenemen?

Ondersteunde configuratie van Fern, Stainless, Speakeasy of ReadMe kan worden omgezet naar een Doctorine-concept, met een overzicht van wat overkwam, wat minder goed overkwam en wat niet wordt ondersteund.
