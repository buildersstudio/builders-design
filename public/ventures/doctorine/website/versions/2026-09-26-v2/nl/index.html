Wat is Doctorine

Een check dat agents en ontwikkelaars je API nog kunnen gebruiken, bij elke wijziging.

Doctorine is een release gate voor API's. Voordat een wijziging live gaat, bewijst het dat coding agents en ontwikkelaars nog echte taken kunnen afronden met je docs, CLI, MCP-server, SDK's en Agent Skills. Het publiceert alleen de interfaces die slaagden en bewaart bewijs van wat er is gecontroleerd.

Het werkt bovenop de docs die je al hebt. Ontbreekt er een interface, dan genereert Doctorine die uit je OpenAPI-spec en gaat die door dezelfde gate.

Begint bij je bestaande docsDe gratis evaluatie leest je publieke docs en spec. Geen migratie, geen productiesleutels.
Draait in je CIEen check op de pull request die de spec wijzigt, naast je andere checks.
Publiceert alleen wat slaagtEen gefaalde interface blijft achter. Elke release laat bewijs achter.
Het probleem

Agents falen niet luid. Ze falen beleefd.

In deze voorbeeldrun las een coding agent de docs, riep de API aan, betaalde 12 cent terug in plaats van 12,50 euro en meldde succes. Er crashte niets, dus niemand maakte een ticket aan.

  • Een retry schrijft de klant twee keer af, omdat de idempotency-header wel in de spec staat maar niet in de docs.
  • Een rapport stopt na de eerste pagina, omdat geen enkel voorbeeld de cursor volgt.
  • Een webhook wordt vertrouwd zonder geldige handtekening, omdat de docs niet zeggen wat er ondertekend is.

Een readinessscore ziet hier niets van. Die controleert of bestanden bestaan, niet of taken slagen.

Een specwijziging leest prima in de review. Daarna stuurt de Python SDK de oude veldnaam, houdt een tutorial het voorbeeld van vorige maand en doet een agent ongemerkt een terugbetaling fout.

Een agent schrijft de wijziging in seconden. Goedkeuren is waar de weken in gaan zitten. Doctorine haalt de mechanische review van de lijst, zodat reviewers alleen beslissen wat een check niet kan.

FAQ

Wat teams als eerste vragen

Wat is Doctorine?

Doctorine is de release gate voor API's. Voordat een API-wijziging live gaat, controleert het of coding agents en ontwikkelaars nog echte taken kunnen afronden met de docs, CLI, MCP-server, SDK's en Agent Skills, publiceert het alleen de interfaces die slaagden en bewaart het bewijs van wat er is gecontroleerd.

Moeten we onze docs migreren?

Nee. Het gratis evaluatierapport leest de docs en spec die je al publiceert, waar ze ook gehost zijn. De release gate draait in je eigen repository. Het Doctorine-portaal is een optie, geen vereiste.

Wat is het verschil met een agent-readinessscore?

Een readinessscore controleert of bestanden als llms.txt, Markdown-pagina's en sitemaps bestaan. De evaluatie laat coding agents echte integratietaken uitvoeren, dus je ziet of een agent echt kan aanmaken, betalen, terugbetalen of opvragen met je API, en waarom het misgaat als dat niet lukt.

Welke interfaces controleert Doctorine?

Het docsportaal, de CLI, de MCP-server, de TypeScript-, Python- en Go-SDK's en Agent Skills. Je controleert de interfaces die je al hebt en genereert de ontbrekende uit je OpenAPI-spec.

Wat kost het?

De Docs Analyser en het evaluatierapport zijn gratis. De release gate is beschikbaar voor designpartners voor 100 euro per maand voor een persoon en 300 euro per maand voor een bedrijf. Publieke abonnementen zijn nog niet gepubliceerd.

Waar worden onze gegevens opgeslagen?

Kerncontent en tenantopslag staan in EU-regio's. Een klein aantal diensten, zoals authenticatie en betalingen, zijn gedocumenteerde uitzonderingen buiten de EU.
