# GET https://docs.acme-payments.example/refunds.md
## Create a refund

POST /v1/refunds

amount  integer, required. Minor units: 1250 is 12.50 EUR.
reason  one of duplicate, fraudulent, requested_by_customer.

Also served as llms.txt, Markdown per page and a sitemap.
docs.acme-payments.exampleGepubliceerd vanuit release 4.13.0
import { AcmePayments } from "@acme/payments";

const acme = new AcmePayments({ apiKey: process.env.ACME_KEY });
const refund = await acme.refunds.create({
  payment: "pay_8Hq2",
  amount: 1250,
  reason: "requested_by_customer",
});

FAQ

Vragen

Met welke interface doen agents het best?

Dat hangt af van de API, daarom rapporteert de evaluatie elke interface apart, met tokens per afgeronde taak.

Moeten we jullie MCP-server gebruiken?

Nee. De evaluatie en de gate controleren de MCP-server die je al draait. Er een genereren is optioneel.
