Docs Analyser: kunnen AI-agents je docs vinden, lezen en gebruiken?

Een gratis check op doctorine.dev. Plak een documentatieportaal en krijg een score van 0 tot 100 voor hoe goed agents het vinden, lezen en gebruiken, met elk signaal dat slaagde, faalde of aandacht vraagt.

Open doctorine.dev →Lees het onderzoek
Wat je krijgt

Een score, vijf categorieën en elke check daarachter.

Elke check zegt geslaagd, mislukt, aandacht nodig of niet te verifiëren, zodat je precies weet welk bestand of welke header je toevoegt.

Analyseer je docs →
Wat het controleert

Vijf categorieën waar agents om geven.

Het resultaat combineert de signalen van de Cloudflare Agent Ready-benchmark met eigen controles van Doctorine.

Agent- en API-vindbaarheidKan een agent je API en tools vinden: een API Catalog, een MCP Server Card, een Agent Skills-index, een machineleesbare spec en discovery-links.
VindbaarheidVindt het de juiste pagina: een llms.txt-index, een sitemap met actuele datums en nette redirects.
Leesbare inhoudKan het de pagina lezen: Markdown voor agents, Markdown-kopieën, pagina's leesbaar zonder JavaScript en de tokenkosten per pagina.
Levering en efficiëntieKomt het efficiënt binnen: gecomprimeerde responses, slim opnieuw ophalen en tijd tot de eerste byte.
Botbeleid en vertrouwenMag het en is het te vertrouwen: robots.txt, content signals, een contentlicentie en een security.txt-contact.
Wat een score niet vertelt

Leesbaar is niet hetzelfde als bruikbaar.

Een portaal kan elke statische check halen en een agent toch halverwege een terugbetaling kwijtraken. De analyser zegt of agents je docs kunnen vinden en lezen. De agenttaken-evaluatie zegt of ze de klus kunnen klaren.

FAQ

Vragen

Is de Docs Analyser gratis?

Ja. Plak een publiek documentatieportaal op doctorine.dev en je krijgt de score en de checklist.

Wat betekent een onvolledige scan?

Als te veel signalen niet te verifiëren zijn, geeft de analyser geen score in plaats van te gokken. In onze meting van september gebeurde dat bij 17 van de 33 portalen, meestal als de controles op de machineleesbare spec en het MCP-endpoint beperkt of niet beschikbaar waren.

Waar komen de checks vandaan?

Het resultaat combineert de signalen van de Cloudflare Agent Ready-benchmark met eigen controles van Doctorine, verdeeld over vijf categorieën.

Betekent een hoge score dat agents onze API kunnen gebruiken?

Niet op zichzelf. Een hoge score betekent dat agents je docs kunnen vinden en lezen. Of ze een taak kunnen afronden, meet de agenttaken-evaluatie.

Ship de wijziging. Houd het bewijs.

Stuur ons je publieke docs en spec, en we laten zien welke echte taken agents vandaag met je API kunnen afronden. Het rapport is gratis en leest alleen wat je al publiceert.
