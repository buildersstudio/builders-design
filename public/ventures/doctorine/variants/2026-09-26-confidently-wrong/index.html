Every failure becomes a pull request and a check.

The fix goes to your repository as a normal pull request. The task that caught it joins your release gate, so the next spec change cannot bring the twelve cents back.

  1. 1Open the fix on your spec or docs, reviewed by you.
  2. 2Add the task to the gate. It runs on every spec change.
  3. 3Publish only the surfaces that passed, with a receipt.
