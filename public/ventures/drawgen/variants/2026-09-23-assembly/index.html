Security and repeatability

Your geometry stays with you. Your drawings stay the same.

In-process

The geometry never leaves the engineer's machine.

drawgen runs in-process inside SOLIDWORKS. The model is read where it already lives, and the PDF and DXF are written to a local folder.

Deterministic

The same model gives the same sheet on every run.

drawgen is deterministic. Run it again on the same model and it returns the same sheet, line for line.
